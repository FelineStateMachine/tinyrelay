# Project extensions

This catalog indexes project-defined interoperability contracts. An extension is not a claim of upstream NIP, GRASP or Blossom standardization. See [Module boundaries and protocol contracts](../module-contracts.md) for the distinction between upstream rules, supported profiles, project extensions and implementation details.

| Identifier | Owner | Status | Specification |
| --- | --- | --- | --- |
| `tinyclient-read-adapter` | `tinyclient` contract and tinyrelay authorization | Experimental | [Read-only frontend/backend HTTP adapter](tinyclient-read-adapter.md) |

The catalog is not yet a complete inventory of existing project-specific behavior. Agent grants and requests, callbacks, custom-view transforms and other custom bindings remain documented in their feature guides pending a wire-contract audit. Add entries as those contracts are checked against their implementation and tests; do not infer compliance or compatibility from a feature's name.
